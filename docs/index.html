01이 페이지에서는 무엇을 할 수 있나요?+

한국어 예시 3개와 영어 예시 2개의 원문·요약을 비교할 수 있어요. 마음에 드는 결과는 복사하거나 텍스트 파일로 저장하고, 선택한 예시의 링크도 공유할 수 있습니다.

02어떤 모델의 결과인가요?+

기존 프로젝트의 한국어 KoBART와 영어 BART 모델로 미리 생성한 결과입니다. 모델 가중치와 생성 설정을 유지했으며, 이 공개 페이지에서는 모델을 실행하거나 외부 AI API를 호출하지 않습니다.

03직접 쓴 글도 요약할 수 있나요?+

이 페이지는 고정된 결과를 소개하는 정적 데모라서 새 글을 요약할 수는 없어요. 실제 추론을 수행하는 원본 프로젝트는 별도의 로컬 서버에서 실행하는 구조입니다. 예시 글은 실제 보도가 아닌 시연용 창작 문서입니다.
